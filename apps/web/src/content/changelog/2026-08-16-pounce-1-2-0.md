Until today, installing Pounce on Linux or Windows got you a small tray app
whose one window showed a pairing QR — the real interface lived on your phone.

**1.2.0 opens the full Pounce UI on the desktop**: the sidebar of every machine
and session, tabs across live conversations, streaming transcripts with images
you can zoom, activity and spend dashboards, theme and appearance switching.
It's the same interface the macOS app has had — the same code, in fact — now
everywhere Pounce runs.

A few things that make this more than a window dressing:

- **Zero-config on its own machine.** The app pairs itself with the bridge it
  ships — open it and your sessions are just there.
- **Your browser is a client now too.** The bridge serves the same UI over the
  LAN, so any machine on your network can open Pounce at this machine's
  address and pair with one link — no install.
- **Port collisions no longer kill the app.** If something else holds Pounce's
  port, a second Pounce attaches to the first, and a foreign program triggers a
  clean fallback to the next free port.
- **Images across machines.** Screenshots an agent drops into a reply now load
  from the machine the thread ran on — on desktop, web, *and* your phone,
  where they used to render as broken images for any remote thread.

The pairing QR hasn't gone anywhere — it moved to the tray menu.

On macOS the native desktop app remains the Pounce experience, and the tray
app stays a tray. Existing installs on every platform update themselves
automatically.
