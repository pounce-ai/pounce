Two fixes from the 1.2.0 work land on the Mac:

- **Screenshots from other machines render.** An image an agent drops into a
  reply names a file on the machine the thread ran on; viewing that thread
  from anywhere else used to draw a broken image. It now loads through the
  host's bridge.
- **Switching light/dark no longer wipes the sidebar.** The sidebar's backdrop
  froze its color from the previous theme, which could leave the whole panel
  illegible until a restart.

Existing installs update themselves automatically.
