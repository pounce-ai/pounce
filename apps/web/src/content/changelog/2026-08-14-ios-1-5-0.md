date: 2026-08-14

---

- **The app stops re-rendering itself.** Every tab used to redraw on each sync
  tick, whether or not anything had changed. State now lives where it is read,
  so scrolling and streaming stay smooth while the fleet syncs behind you.
- **The attention shelf no longer overstates things.** A thread you can pick
  back up is now marked as exactly that, and a run that failed can be
  dismissed instead of sitting in the shelf forever.
- **Machines added over SSH keep the name you dialled.** The address you typed
  is the name you see, and a machine added over SSH is shown for what it is
  rather than guessed at from its hostname.
- **See what each agent's plan has left.** Usage is metered per agent, a
  project lists the skills it has available, and worktree disk can be reclaimed
  from the app.
- Fixes: the paste-a-code header is actually tappable, a disclosure that can't
  animate no longer tries to, and the Changes sheet renders correctly on
  device.

Android ships the same release as version code 21.
