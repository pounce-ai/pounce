The desktop app is now Apple Silicon only. Intel Macs are no longer supported —
if you're on one, run `npx use-pounce` and drive that Mac from your phone
instead.

Also in this release: modals all have a visible way out, project context is
verified on the desktop, and cost is reported straight from the agent rather
than estimated. Existing Apple Silicon installs update themselves
automatically.
