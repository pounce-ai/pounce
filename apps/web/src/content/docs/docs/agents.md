Pounce drives the agent CLIs already installed on your machine. No extra
accounts, no API keys handed to Pounce — if an agent works in your terminal,
it shows up on your phone.

| Agent           | CLI            |
| --------------- | -------------- |
| **Claude Code** | `claude`       |
| **Codex**       | `codex`        |
| **Cursor**      | `cursor-agent` |
| **opencode**    | `opencode`     |

## What works

For every supported agent:

- **Full history** — every session the agent has on that machine appears in
  Pounce, not just the ones you start from the phone.
- **Live streaming** — reasoning, tool calls, and file edits stream to your
  phone in real time while the agent works.
- **Start & steer** — kick off new sessions from the phone, reply
  mid-session, or redirect an agent that's headed the wrong way.
- **Interactive prompts** — permission requests, plan approvals,
  multiple-choice questions: whatever the CLI asks, you can answer from your
  phone.
- **Diffs & shipping** — review the changes a session made, then commit,
  push, or open a PR.

## Where the agents run

Agents always run on **your computer**, under your own accounts and logins —
Pounce is the remote, not the runtime. Sessions you start from your phone are
the same sessions you can pick up later at your desk.
